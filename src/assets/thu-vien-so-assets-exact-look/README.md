# Bộ asset bám sát ảnh mẫu

Tổng số asset: 80

Các file `.svg` trong bộ này **nhúng ảnh PNG đã cắt và xóa nền**, nhằm giữ hình ảnh gần như y hệt ảnh mẫu.

Ưu điểm:
- Hiển thị sát mẫu.
- Dùng trực tiếp bằng `<img>`.
- Không vỡ đường dẫn khi chuyển project.
- Có nền trong suốt.

Giới hạn:
- Không phải SVG vector path thuần.
- Không thể đổi hình dáng từng chi tiết bằng CSS.
- Muốn vector path thật cần vẽ lại thủ công từng asset trong Figma/Illustrator.

Xem `manifest.json` để có danh sách đầy đủ.
